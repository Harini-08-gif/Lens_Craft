# LenCraft

LenCraft is a modern, responsive web application designed for seamless visual discovery and image searching.

## Design Decisions
1. **Dark Cyan & Emerald Color Palette**: Chosen over standard dark modes to provide a distinct, immersive visual aesthetic suited for photo browsing.
2. **Quick-Pick Suggestion Chips**: Integrated directly beneath the search bar to allow users to trigger searches for popular image categories with a single click.
